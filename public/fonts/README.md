# Resume PDF font

Noto Sans SC, SIL Open Font License (see OFL.txt), downloaded from the
[official Noto CJK repository](https://github.com/notofonts/noto-cjk/blob/main/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf).

The variable TTF was instantiated at weight 400 with fontTools and saved as
static TTF (no glyph subsetting; GSUB, GPOS and GDEF removed, so no optional ligatures or kerning). The complete character set supports future content
updates. It is fetched from this site's origin only when exporting Chinese.
Latin-language PDFs use the renderer's standard Helvetica fonts.
